1. Что вообще проверяет задание 22

Модель задачи

Есть несколько вычислительных процессов. У каждого процесса обычно даны:

  • ID — идентификатор процесса;
  • длительность — сколько миллисекунд он выполняется;
  • зависимости — ID процессов, результаты которых нужны для запуска текущего процесса.

Если в зависимостях стоит 0, процесс независимый: он может стартовать с момента времени 0, если в условии не сказано иначе.

Главная идея: зависимый процесс ждёт завершения всех процессов-предков. Если предков несколько, важен не первый завершившийся, а самый поздний из них.

Что важно для 2026

Файл к заданию 22 в ЕГЭ-2026 обычно даётся как таблица .ods. Поэтому основной рабочий инструмент — LibreOffice Calc или Excel, если файл корректно открывается.

Экзаменационный смысл: это не задача на красивое программирование. Это задача на аккуратную модель, таблицы, формулы и внимательное чтение условия.

2. Базовая теория и главные формулы

Время начала и окончания

Для каждого процесса удобно считать два числа:

  • Start — момент начала процесса;
  • End — момент окончания процесса.
Start = max(End всех зависимостей) End = Start + Duration

Для независимого процесса:

Start = 0 End = Duration

Если есть задержка

Иногда в условии пишут: «процесс может начаться не раньше, чем через X мс после завершения входящего процесса».

Start = max(End зависимостей) + X End = Start + Duration
Ловушка: задержку добавляют зависимым процессам. Независимые процессы не ждут эту задержку, если в условии отдельно не сказано обратное.

Почему берём максимум, а не сумму

Если процесс зависит от процессов 1 и 2, он не выполняет их заново и не ждёт их по очереди. Они могли идти параллельно. Он просто ждёт, пока закончится последний из нужных процессов.

ПроцессДлительностьЗависит отStartEnd
14004
23003
311; 2max(4, 3) = 45
473512
Ответ на «минимальное время выполнения всех процессов»: максимальное значение в столбце End. В примере это 12.

3. Как решать в Excel / LibreOffice Calc

Стандартная раскладка столбцов

Удобная структура после разбиения зависимостей:

СтолбецЧто хранитьПример
AID процесса1, 2, 3...
BДлительность4, 12, 7...
CИсходная строка зависимостей1; 2; 8 или 0
D:FРазбитые зависимостиD = 1, E = 2, F = 8
GStart — время начала0, 4, 15...
HEnd — время окончания4, 12, 22...
Открой файл .ods. Не переписывай таблицу руками, работай с готовыми данными.
Разбей зависимости. Выдели столбец зависимостей → Данные → Текст по столбцам → разделитель ;.
Пустые ячейки в зависимостях замени на 0. Делай это только в столбцах зависимостей, не во всей таблице.
Добавь столбцы Start и End. Считай начало через максимум окончаний зависимостей, окончание — как начало + длительность.
Смотри вопрос. Не всегда ответ — максимум End. Иногда спрашивают количество процессов, интервал, момент времени или параметр.

Формулы без задержки

Пусть ID в A, длительность в B, зависимости в D:F, Start в G, End в H.

Формула для G2:

=МАКС(ЕСЛИОШИБКА(ВПР(D2;$A$2:$H$200;8;0);0);ЕСЛИОШИБКА(ВПР(E2;$A$2:$H$200;8;0);0);ЕСЛИОШИБКА(ВПР(F2;$A$2:$H$200;8;0);0))

Формула для H2:

=G2+B2

Протяни обе формулы вниз.

Формулы с задержкой X мс

Если задержка записана в ячейке K1, а у независимого процесса в D2 стоит 0:

=ЕСЛИ(D2=0;0;МАКС(ЕСЛИОШИБКА(ВПР(D2;$A$2:$H$200;8;0);0);ЕСЛИОШИБКА(ВПР(E2;$A$2:$H$200;8;0);0);ЕСЛИОШИБКА(ВПР(F2;$A$2:$H$200;8;0);0))+$K$1)

Окончание такое же:

=G2+B2

Супер-лайфхак: строка ID = 0

Чтобы не ловить ошибки #Н/Д, можно добавить техническую строку:

IDДлительностьЗависимостиStartEnd
00000

Тогда ВПР(0;...) вернёт 0, и формулы становятся спокойнее. Но следи, чтобы диапазон ВПР начинался с этой строки.

4. Типы вопросов и что именно считать

Тип 1. Минимальное время выполнения всех процессов

Считаешь End для всех процессов. Ответ — максимум.

Ответ = МАКС(столбец End)
Триггер: «Определите минимальное время, через которое завершится выполнение всей совокупности процессов».

Тип 2. Сколько процессов завершится за первые T мс

Процесс завершился за первые T мс, если его End ≤ T.

=H2<=T

Потом фильтр по ИСТИНА или подсчёт.

Триггер: «какое наибольшее количество процессов может быть завершено за первые 200 мс».

Тип 3. Сколько процессов выполняется в N-ю миллисекунду

N-я миллисекунда — это промежуток от N−1 до N. Например, 15-я мс — от 14 до 15.

Процесс активен на N-й мс, если:

Start < N End >= N

В таблице:

=И(G2<15;H2>=15)
Ловушка: не писать Start ≤ N. Процесс, который стартует ровно в 15, не выполнялся в течение 15-й мс, он начался после неё.

Тип 4. Максимальное число одновременно выполняющихся процессов

Строишь временную шкалу: 1, 2, 3, ..., максимум End. Для каждого момента считаешь, сколько процессов активны.

=ЕСЛИ(И($G2<J$1;$H2>=J$1);1;0)

Внизу каждого столбца:

=СУММ(J2:J200)

Ответ — максимум по строке сумм.

Тип 5. Максимальная длина отрезка, когда работают ≥ K процессов

Сначала считаешь количество активных процессов в каждый момент. Потом считаешь длину непрерывной серии.

=ЕСЛИ(J$201>=$K$1;I202+1;0)

Где J$201 — количество активных процессов в текущую миллисекунду, $K$1 — нужный порог.

Триггер: «максимальная продолжительность отрезка времени, в течение которого одновременно выполнялось не менее K процессов».

Тип 6. Неизвестная длительность t

В ячейку с t временно ставишь число. Таблица пересчитывается. Подбираешь максимальное t, при котором условие выполняется.

Общее время = МАКС(End) Нужно: Общее время <= лимит
Лайфхак: можно использовать «Данные → Анализ “что если” → Подбор параметра», но на ЕГЭ часто быстрее подобрать руками: 1 → 10 → 20 → середина → проверить t и t+1.

6. Примеры решений

Пример A. Минимальное время выполнения

IDДлит.ЗависитStartEnd

Ответ: max(4,3,5,12)=12.

Пример B. Задержка 7 мс

Пусть процесс 3 зависит от 1 и 2, а процесс может стартовать не раньше, чем через 7 мс после завершения входящих процессов.

Start3 = max(End1, End2) + 7 End3 = Start3 + Duration3

Если End1=4, End2=3, длительность процесса 3 равна 1, то:

Start3 = max(4,3)+7 = 11 End3 = 11+1 = 12

Пример C. Активен ли процесс на 15-й мс

15-я миллисекунда — это отрезок от 14 до 15. Проверяем:

StartEndРаботает на 15-й мс?Почему
1015Да10 < 15 и 15 ≥ 15
1520НетСтарт ровно в 15, значит не работал на отрезке 14–15
714НетЗакончился до конца 15-й мс
1416ДаЗахватывает отрезок 14–15

Пример D. Неизвестное t

У одного процесса длительность t. Известно: все процессы должны завершиться не более чем за 96 мс.

  1. Ставим вместо t число 1.
  2. Считаем все Start и End.
  3. Смотрим МАКС(End).
  4. Увеличиваем t, пока максимум не станет близок к 96.
  5. Проверяем найденное t и обязательно t+1.
Ответом будет максимальное t, при котором МАКС(End) ≤ 96.

7. Лайфхаки для экзамена

1. Сначала читай последний вопрос.
Не начинай считать, пока не понял, что спрашивают: время всех процессов, количество активных, завершившихся, максимум отрезка или параметр.
2. Не рисуй большую диаграмму руками.
4 процесса можно на бумаге. 20, 100, 130 процессов — только таблица.
3. Разбивай зависимости через «Текст по столбцам».
Разделитель почти всегда ;. После разбиения легче делать ВПР.
4. Фиксируй диапазоны знаками $.
Пиши $A$2:$H$200, иначе при протягивании формулы диапазон уедет.
5. Оборачивай ВПР в ЕСЛИОШИБКА.
Это спасает от пустых зависимостей и лишних столбцов.
6. Делай технический ID 0.
Строка ID=0, End=0 уменьшает количество ошибок.
7. Для подсчёта количества используй фильтр.
Столбец ИСТИНА/ЛОЖЬ → фильтр по ИСТИНА → смотри «Количество» внизу.
8. Проверяй миллисекунды на маленьком примере.
Если сомневаешься в < и ≥, нарисуй отрезок: N-я мс = от N−1 до N.
9. Не добавляй задержку всем подряд.
Если задержка после завершения входящих процессов, независимые процессы стартуют в 0.
10. После ответа проверь край.
Для t: проверь t подходит, t+1 уже не подходит.

9. Чек-лист решения за 7 минут

Прочитай вопрос. Что ищем: время, количество, момент, интервал, параметр?
Открой .ods. Проверь, где ID, длительность, зависимости.
Разбей зависимости по ;. Получи отдельные столбцы зависимостей.
Создай Start и End. Start = максимум окончаний зависимостей, End = Start + длительность.
Учти особые слова. Задержка, N-я миллисекунда, первые T мс, неизвестное t, сдвиги.
Получай ответ нужным способом. Max End, Count End≤T, Count active, Max streak, подбор t.
Проверь крайний случай. Особенно знаки </≥, задержку и t+1.
